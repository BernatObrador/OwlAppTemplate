# Creating reusable components

[Documentation index](README.md) · [DataTable](DATA_TABLE.md) · [Forms](BASE_FORM.md)

```bash
npm run component -- StatusBadge
```

The generator creates `src/components/StatusBadge/StatusBadge.js` and `.xml`, with a matching static template name and t-name. Existing files are never overwritten. Components receive props and emit callbacks; pages own domain state and API calls.

```js
import { Component } from "@odoo/owl";

export class StatusBadge extends Component {
  static template = "components.StatusBadge";
  static props = { label: String };
}
```

```xml
<templates xml:space="preserve">
  <t t-name="components.StatusBadge">
    <span class="app-badge" t-esc="props.label"/>
  </t>
</templates>
```

Import and register the class in its parent's `static components`, then render `<StatusBadge label="'Active'"/>`. OWL component attributes are JavaScript expressions: quote string literals inside the XML attribute. Use `.bind` for method callbacks, for example `onInput.bind="search"`. Keep complex calculations in getters or JavaScript methods.

All XML files under src are discovered by loadTemplates. Names must be unique and match static template declarations. `npm run check` parses and compiles them and checks local imports and template references. Files generated by the scripts follow these conventions automatically.

## FormField

FormField consolidates shared labels, help and error rendering for text, email, password, number, date, select, textarea and checkbox controls.

Required props: name, label, value and onInput(value). Optional props: id, type, placeholder, required, disabled, loading, error, help, options, rows, min, max, step and autocomplete. id defaults to name; provide an explicit unique ID when two fields share a name on one screen. loading also disables the control.

```xml
<FormField name="'stage'" label="'Stage'" type="'select'"
  value="state.form.stage" options="stageOptions"
  error="state.errors.stage" disabled="state.saving"
  onInput="(value) => this.setField('stage', value)"/>
```

Options are `{ value, label, disabled? }`. Select emits the original option value, including numeric values. Number emits a number or an empty string; checkbox emits a boolean; date emits the native date string. Handle an empty numeric value in domain validation. Help and errors are linked with aria-describedby; errors set aria-invalid. Native required/min/max validation complements, but does not replace, business validation.
